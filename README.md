# D4D

D4D 프로젝트 관련 코드와 실행 자료를 보관하는 저장소입니다.

## 파일 안내

- `ventuno_wifi_semantic.zip`: Ventuno Wi-Fi 시맨틱 파이프라인 자료
- `vlm_pipeline_wifi.zip`: VLM 기반 Wi-Fi 파이프라인 자료

## 다운로드

이 저장소의 대용량 ZIP 파일은 Git LFS로 관리됩니다. 저장소를 복제한 뒤 파일이 정상적으로 내려받아지지 않는다면 Git LFS를 설치하고 다음 명령을 실행하세요.

```bash
git lfs install
git lfs pull
```

## 참고

압축을 해제한 뒤 각 폴더에 포함된 문서와 실행 파일을 확인해 주세요. 실행 환경과 의존성은 파이프라인별로 다를 수 있습니다.
